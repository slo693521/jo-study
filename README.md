# 日本語ノート：N5 自學系統

這是給零基礎中文使用者的日文自學網站，目標是用 6 個月（26 週，每天 30–45 分鐘）學到 JLPT N5 程度。網站只用 HTML、CSS 和 JavaScript 寫成，沒有後端，也不需要帳號或付費 API。學習資料都存在你自己的瀏覽器裡。

> ⚠️ 學完這套系統**不等於**通過 JLPT N5。所有教材和題目都是自己編寫的，不含任何官方試題。模擬考的分數換算只能拿來自我檢測。報考前請另外做官方公開的樣題，並以官方公告為準。

## 啟動方式

建議用本機 HTTP 伺服器開啟。不要直接雙擊 `index.html`：多數功能在 `file://` 下也能用，但部分瀏覽器會限制儲存和語音功能。

```bash
cd jp-study-app
python3 -m http.server 8000
```

接著用瀏覽器開啟 <http://localhost:8000/>。

- 沒有 Python 的話：`npx serve .`（需要 Node.js），或用 VS Code 的 Live Server 擴充套件。
- **手機使用**：已發佈到 GitHub Pages，手機瀏覽器直接開，並可「加入主畫面」當 App 用，離線也能學。修改程式後重新推送即可更新。
- 手機與電腦的進度不會自動同步：到「設定與備份」按「📋 複製備份文字」，傳到另一台後按「📥 貼上備份文字匯入」（選「合併」）。
- 手機想連電腦上的網站時，電腦端改成 `python3 -m http.server 8000 --bind 0.0.0.0`，手機再開 `http://電腦的區網IP:8000/`。注意：每個網址（包括 IP 和埠號）的學習紀錄是分開存的。
- 建議用 Chrome、Edge 或 Safari 的新版本。

## 每天怎麼用

1. 打開首頁，按「▶ 開始今日課程」，系統會帶你到今天第一項還沒做的任務。
2. 每天的流程是：**複習舊單字**（約 5 分）→ 學習新教材（10–15 分）→ 單字與文法練習（5–10 分）→ 聽力或跟讀（5–10 分）→ 每日測驗（5 分）。
3. 一課要同時做到下面三項才算完成：
   - 讀完教材並按「我讀完了」
   - 本課單字全部學過
   - 本課測驗達到 80% 以上
4. 系統會依進度自動調整任務：
   - 前一課測驗低於 70%，今天會先排複習那一課。
   - 每週日（或距離上次超過 7 天）加一份每週複習。
   - 每 28 天加一次階段測驗。
   - 最後兩課是兩回模擬考。

### 快速鍵

- 單字卡：空白鍵或 Enter 顯示答案，1–4 評分，P 朗讀，F 收藏
- 測驗：1–4 或 A–D 選答案，Enter 下一題
- Esc：關閉視窗或選單

## 備份（重要）

- 學習進度存在瀏覽器的 **localStorage**，這**不是雲端備份**。清除瀏覽資料、用無痕模式、換瀏覽器或換電腦，進度都會不見。
- 請定期到「設定與備份 → 匯出備份」下載 JSON 檔，並存到雲端硬碟或隨身碟。超過 14 天沒有匯出時，首頁會提醒你。
- 匯入時有兩種方式：
  - 合併（建議）：保留目前的資料，再把備份中較新或較多的進度併進來。
  - 取代：完全換成備份檔的內容。
- 匯入前系統會先檢查檔案格式，格式不對的檔案會被拒絕，現有資料不會改變。

## 日文語音

- 朗讀使用瀏覽器內建的語音合成（Web Speech API）。系統指定 `lang = ja-JP`，而且只會挑語言為日文的語音。
- 找不到日文語音時，畫面會明確提示，系統**不會改用中文或其他語言的聲音念日文**，也不會假裝有在播放。
- 這些都是**電腦合成語音，不是真人錄音**。
- 如何安裝日文語音：
  - Windows：設定 → 時間與語言 → 語音 → 新增語音 → 日本語
  - macOS：系統設定 → 輔助使用 → 語音內容 → 系統語音 → 管理語音 → 日文
  - Android：設定 → 文字轉語音 → 安裝日文語音資料
  - iOS：設定 → 輔助使用 → 朗讀內容 → 聲音 → 日文
- Chrome 的部分日文語音是線上語音，需要網路才能使用。可以到「設定」頁按「測試日文語音」確認。

### 改用真人錄音檔

1. 把音檔放進 `audio/` 資料夾。
2. 在 `data/audiomap.js` 登記：鍵是「日文原文去掉所有空白」，值是音檔路徑。
   ```js
   window.JP_AUDIO_MAP = { '私は学生です。': 'audio/l14-01.mp3' };
   ```
3. 執行 `node tests/list-audio-keys.js > audio-keys.txt`，可以列出全部 1,829 個朗讀鍵。

有登記音檔的句子會優先播放音檔，其他句子仍使用合成語音。請只使用你有權使用的錄音。

## 教材格式（給想修改教材的人）

- 日文句子用 `漢字[かな]` 標注振假名，詞與詞之間用空白分開，例如 `私[わたし] は 学生[がくせい] です 。`。需要時可以加 `{中文}` 補充逐詞解釋。
- 讀音、羅馬拼音、逐詞拆解和朗讀文字都從同一個字串產生，所以不會出現互相對不上的情況。
- 改完教材後請執行 `node tests/validate.js`。它會檢查：
  - 讀音和振假名是否正確對齊
  - 例句裡的每個詞能不能解釋，讀音是否和單字庫一致
  - 例句是否真的包含該單字，有沒有重複單字
  - 答案是否出現在選項中
  - 正確答案的位置分布是否平均
  - 約 9,900 題自動產生的題目是否正確

## 測試

```bash
node tests/validate.js                 # 教材驗證
python3 -m http.server 8000 &          # 另開伺服器
```

## 已知限制

- 語音的有無和品質取決於瀏覽器與作業系統。部分手機在螢幕關閉或切到背景時會中斷朗讀。Android 的暫停功能不穩定，所以系統的「暫停」實際做法是停在目前這句，按繼續時從這句開頭重念。
- 沒有發音評分和手寫辨識功能。跟讀時要靠自己對照判斷。
- 只用 localStorage 儲存，不同瀏覽器或裝置之間不會自動同步，需要手動匯出再匯入。
- 教材已經用程式檢查過讀音和答案，也逐條人工複查過一次（見 REVIEW-CHANGES.md），但仍是自編內容，可能有疏漏。有疑問時請以字典或日語老師為準。
